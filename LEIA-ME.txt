SANT'S LAVA CAR - CÓDIGO DO APP (GITHUB)
Cópia do repositório santslavacar/santslavacar.github.io, versão que está no ar em 10/11/2026.

ARQUIVOS
- index.html ...... página inicial do app
- app.js .......... todo o funcionamento (login, agenda, painel, pedidos)
- data.js ......... lista de marcas e modelos com o porte de cada um
- style.css ....... visual (cores, tema claro e escuro)
- manifest.json ... nome e ícone ao instalar na tela do celular
- firestore.rules . regras de segurança do banco (cópia, a usada fica no Firebase)
- img/ ............ banner, ícones e fotos de antes e depois

COMO PUBLICAR NA CONTA DO GEOVANE
Faça antes o passo a passo do arquivo do banco de dados, porque ele gera a configuração usada no passo 2.

1. Troque a ligação com o Firebase no app.js
   Abra o app.js num editor de texto (Bloco de Notas serve).
   - Procure "const FB=" (perto do início) e troque tudo entre { } pela configuração do projeto novo do Firebase.
   - Procure "const EMPRESAS=" e deixe só os e-mails que terão acesso de empresa, entre aspas simples e separados por vírgula.
     Exemplo: const EMPRESAS=['geovanesantosx1999@gmail.com'];

2. Crie o repositório no GitHub
   - Entre no GitHub com a conta dele e clique em New repository.
   - Para o endereço ficar curto, o nome do repositório deve ser SEUUSUARIO.github.io (trocando SEUUSUARIO pelo usuário dele).
     Qualquer outro nome deixa o endereço como SEUUSUARIO.github.io/NOME.
   - Marque Public e clique em Create repository.

3. Envie os arquivos
   - No repositório novo, clique em "uploading an existing file".
   - Arraste todos os arquivos desta pasta, incluindo a pasta img.
   - Clique em Commit changes.

4. Ligue o site
   - Vá em Settings > Pages.
   - Em Source, escolha Deploy from a branch, branch main, pasta / (root), e salve.
   - Em 1 a 5 minutos o endereço aparece no topo dessa tela.

5. Troque o link na bio do Instagram e no WhatsApp pelo endereço novo.

ATUALIZAÇÕES FUTURAS
Ao alterar app.js ou style.css, mude o número no index.html (app.js?v=5 vira app.js?v=6, o mesmo em style.css). Isso faz os celulares baixarem a versão nova.
